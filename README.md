# Shatter

Shatter is a fast gravity-well rock shooter. Pilot an inertial ship, strip armor from tumbling rocks, split them into fragments, and curve shots around the central star. A hunting saucer joins the fight, while one self-guided Warhead offers a decisive shot every ten seconds.

## Run it

```sh
npm ci
npm run dev
```

Open the URL printed by Vite. Build the static production site in `dist/` with `npm run build`.

## Controls

- **Arrow keys / WASD** — turn and thrust
- **Space** — fire
- **F** — launch the guided Warhead
- **Enter / Space** — confirm menus
- **Escape / P** — pause, resume, or go back
- **M** — mute
- **Backtick** — diagnostics

Menus support mouse and touch. Touch devices also receive on-screen flight controls.
